# Карта скиллов контента

52 скилла из [Ootto-AI/claude-content-skills](https://github.com/Ootto-AI/claude-content-skills)
(MIT, см. `LICENSE-claude-content-skills`). Каждый лежит в своей папке как `SKILL.md` и
вызывается командой `/<имя>`. Этот файл — сводка, чтобы быстро выбрать нужный скилл и не
нарушить общие правила.

## Конвейер рилса (идея → лиды)

```
ai-brain (память) → agent-reach / content-research / trend-spotter (найти формат)
  → reel-analyzer (разбор) → going-viral (цель и эмоция)
  → viral-hook-writer / hook-mining / ab-hook-tester (хук)
  → reel-scripter (сценарий) → on-screen-text-writer, b-roll-shot-list
  → reel-builder (+reel = рендер в Remotion) → cover-thumbnail-brief
  → caption-and-hashtags, hashtag-keyword-research, cta-writer
  → публикация → comment-responder + dm-script-writer (лиды)
  → analytics-readout / content-audit → обратно в ai-brain
```

`content-factory` запускает весь конвейер одной командой.

## Общие правила (из всех скиллов)

1. **Никаких выдуманных цифр, цитат и фактов.** Всё, что попадает на экран, проверяется по источнику, источники сохраняются в проекте.
2. **Брать формат, а не слова.** Чужие тексты дословно не используем: это плагиат, и Instagram режет охват копий.
3. **Хук решает.** Главный элемент в кадре с первого кадра, суть — к ~1,5 с, понятно без звука.
4. **Одна цель и один призыв на ролик.**
5. **Обещать только то, что реально отправится.** Слово-триггер в CTA должно быть подключено к автоответу до публикации.
6. **Ссылка — только в DM**, не в публичном ответе.
7. **Без автоматических непрошеных сообщений и скрытой рекламы.**
8. **Ничего не публиковать без «ок» пользователя.**

## Что нужно подключить

- Remotion — рендер (`npm i remotion @remotion/cli`); в облаке нужен `headless_shell`, см. `projects/*/README.md`.
- Apify MCP — разбор рилсов; Composio MCP → Instagram — публикация и DM; Runway — генерация видео (Seedance).
- Filesystem MCP → папка Obsidian — для `ai-brain`.
- `agent-reach` использует свои CLI (`yt-dlp`, `mcporter` и др.), их нужно установить отдельно.

## Практика

- Темп речи для русского текста ~2,5–3 слова в секунду: 45 с ≈ 115–130 слов.
- Перед отправкой — смотреть кадры рендера, а не доверять коду: наложения текста и вылеты за край видны только на кадрах.
