# Рилс: дом Тадао Андо без окон (Канье Уэст × Тони Саксон)

- Формат: 9:16, 1080×1920, 30 fps, 45 с
- Скилл: `reel-builder` (+reel, рендер в Remotion)
- Статус: черновой монтаж готов; футаж и голос — заглушки (метки «▶ ФУТАЖ: …» в кадре)

## Рендер

```bash
npm install
npx remotion render src/index.ts Reel out/reel.mp4 \
  --browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell
```

В облачной сессии Claude Code обычный Chromium не стартует в старом headless-режиме, поэтому нужен
`headless_shell`. Локально флаг `--browser-executable` можно убрать.

## Проверка фактов

- $140 000 = $100 000 (медицинские расходы) + $40 000 (перенесённые страдания), не «потерянный доход».
- Незаконное увольнение присяжные не признали, штрафных выплат нет.
- Юристы Уэста требуют отменить решение; об апелляции в источниках не сказано.
- «Бункер образца 1910-х» не подтверждён — год убран.
