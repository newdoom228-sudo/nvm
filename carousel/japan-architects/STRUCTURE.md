# Шаблон карусели «Архитектурная духота от Джорно»

Структура собрана по логике длинных материалов Dezeen, Wallpaper*, Monocle, Casa BRUTUS и The Architectural Review,
переложенной на 8 слайдов Instagram (1818×2000, как исходные посты).

| # | Роль слайда | Что на нём |
|---|---|---|
| 1 | Обложка-хук | Мелкий моно-подзаголовок сверху («ИЛИ КАК ВЛЮБИТЬСЯ В …»), огромное красное рукописное слово, цифры (N имён / N лет), большая лого-голова, ироничная реплика |
| 2 | Лид / контекст | Красный рукописный заголовок, моно-абзац с красными датами, таймлайн со всеми героями |
| 3–7 | Карточки героев (один шаблон) | Сверху: «ГОД.» красным + моно-лид · справа: большой номер 01–05, имя, годы жизни · по центру: иллюстрация с наложенной красной рукописной подписью · снизу: моно «почему это важно» · лого-голова слева внизу · красная реплика «— …» справа внизу |
| 8 | Вывод + CTA | «Что забрать с собой» — 3 урока · диалог двух голов (Джорно и «Москвичка» Vesper) · призыв в комментарии / «сохрани» |

## Визуальная система
- Фон: чистый белый. Акцент: красный `#E3172B`. Текст: `#111`.
- Заголовки и реплики: GoodDog капсом (`assets/fonts/GoodDogCyr.ttf` — кириллица дособрана из латинских глифов GoodDog скриптом `build_gd_cyr.py`).
- Основной текст: Cascadia Code капсом, жирный — для имён.
- Графика и плашки — glassmorphism: полупрозрачное стекло (blur 30px, белая кромка, блик) поверх размытых красных пятен.
- Motion: появление из размытия по очереди, медленный наезд на фото, блик по стеклу, дрейф пятен. 6 с, MP4 1080×1188 (`node render.js --video`).
- Лого-голова Джорно — на каждом слайде, слева внизу. Голова Vesper — только в финальном диалоге.
- Каждый слайд заканчивается самоироничной красной репликой (как «— НО ПОЧЕМУ Я НЕ ВСТУПИЛ В ДИАЛОГ?»).

## Тон
Факт → цифра → поворот → шутка. Короткие фразы, одна мысль на абзац, без пафоса.
